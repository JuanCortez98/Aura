# Aura Beauty Studio · demo comercial de Dorenio

- Marca ficticia. **No** admite reservas ni pagos reales.
- Promociones y precios: referencias ilustrativas que requieren confirmación con el negocio.
- Botón flotante de WhatsApp: abre un simulador de consulta, no un chat real de Aura.
- AgendaPro: enlace a la página oficial de la plataforma, **no** a una agenda de Aura. Para una empresa real, sustituir con el enlace público de reserva proporcionado por el titular.
- Google Maps: muestra Mérida, Yucatán como ejemplo, **no** una ubicación exacta del salón. Sustituir la URL del iframe y del vínculo con la dirección verificada del cliente.
- Instagram y Facebook son las cuentas de **Dorenio**, etiquetadas como tal. Cambiar por las cuentas reales cuando exista un cliente.
- Las fotografías requieren autorización de uso público antes de desplegar el demo.
- La solicitud de cotización y reserva puede conectarse a WhatsApp o AgendaPro del cliente tras obtener sus enlaces oficiales.

Abre `index.html` con Live Server. La web principal Dorenio conserva su enlace a este demo.
